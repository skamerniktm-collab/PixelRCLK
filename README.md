# PixelRCLK

Мобильное приложение на Kotlin / Gradle для работы с изображениями и текстурами: редактирования, масштабирования (ресайза), наложения слоёв и сжатия.

## Основные возможности

* **Редактор** — базовая правка и подготовка изображений.
* **Ресайз** — изменение размеров изображений по заданным параметрам и пресетам.
* **Наложение** — добавление и позиционирование слоёв поверх изображения.
* **Сжатие** — уменьшение веса файлов для удобного хранения и переноса.

## Структура проекта

* `build.gradle.kts` / `settings.gradle.kts` / `gradle.properties` — конфигурация сборки Gradle.
* `.env.example` — шаблон переменных окружения.
* `.gitignore` — правила исключения временных и служебных файлов.
* `metadata.json` — метаданные проекта.

## Сборка и запуск

1. Откройте проект в среде разработки с поддержкой Gradle (например, Android Studio).
2. Синхронизируйте зависимости Gradle.
3. Соберите и запустите приложение на устройстве или эмуляторе.

Проект распространяется под лицензией **AGPL-3.0** (см. файл `ЛИЦЕНЗИЯ`).
